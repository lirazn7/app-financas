# 📊 Assistente Financeiro IA

Um aplicativo web *mobile-first* de gestão financeira inteligente que utiliza **Visão Computacional** e Inteligência Artificial para ler cupons fiscais, extrair dados automaticamente e gerenciar orçamentos pessoais em um painel interativo.

## 🚀 O que o projeto faz?

O Assistente Financeiro elimina o trabalho manual e tedioso de registrar gastos. Através de uma interface limpa e intuitiva, o usuário tira uma foto (ou faz o upload) de uma nota fiscal. O aplicativo processa a imagem usando IA generativa de visão, extrai os dados estruturados (estabelecimento, valor, categoria, etc.) e salva diretamente em um banco de dados em nuvem. 

Além disso, o aplicativo oferece um **Dashboard Financeiro Completo** onde o usuário pode:
*   Analisar gráficos dinâmicos de gastos por categoria, forma de pagamento e histórico diário/mensal.
*   Filtrar despesas por mês específico ou visualizar o histórico completo.
*   **Gestão de Orçamento (Budgeting):** Definir tetos de gastos mensais por categoria e acompanhar o consumo em tempo real através de barras de progresso visuais.
*   Editar ou excluir registros pontuais no histórico.

## 🏗️ Arquitetura e Tecnologias

O projeto foi construído utilizando as ferramentas mais modernas do ecossistema React, focado em alta performance e escalabilidade (Serverless).

*   **Front-end:** [Next.js (App Router)](https://nextjs.org/) + React
*   **Estilização:** [Tailwind CSS](https://tailwindcss.com/) + [Lucide Icons](https://lucide.dev/)
*   **Gráficos:** [Chart.js](https://www.chartjs.org/) + `react-chartjs-2`
*   **Autenticação e Banco de Dados:** [Supabase](https://supabase.com/) (PostgreSQL) com *Row Level Security* (RLS).
*   **Inteligência Artificial:** API [OpenRouter](https://openrouter.ai/) utilizando o modelo de visão multimodal **Qwen 2.5 VL 72B Instruct** via *fetch* nativo.
*   **Hospedagem (Deploy):** [Vercel](https://vercel.com/)

### 🔐 Segurança Multi-usuário (RLS)
A arquitetura de dados conta com **Sessões Persistentes** e políticas de *Row Level Security* (RLS) habilitadas no Supabase. Isso garante que múltiplos usuários (ex: familiares ou colegas de trabalho) possam utilizar o mesmo aplicativo simulando ambientes isolados; o usuário "A" nunca terá acesso ou enxergará as despesas e limites orçamentários do usuário "B".

## 💻 Como rodar o projeto localmente

Siga o passo a passo abaixo para clonar e rodar o projeto em sua máquina.

### 1. Pré-requisitos
*   [Node.js](https://nodejs.org/) instalado (versão 18+ recomendada)
*   Conta ativa no [Supabase](https://supabase.com/) (para o banco de dados e autenticação)
*   Conta no [OpenRouter](https://openrouter.ai/) (para a chave de API da IA de Visão)

### 2. Configuração do Banco de Dados (Supabase)
Crie um novo projeto no Supabase, acesse o **SQL Editor** e execute os scripts de criação de tabelas:

```sql
-- Criação da tabela de Gastos
CREATE TABLE public.gastos (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  user_id uuid references auth.users(id) on delete cascade not null,
  estabelecimento text not null,
  valor numeric(10,2) not null,
  data_compra date,
  categoria text,
  forma_pagamento text
);

ALTER TABLE public.gastos ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Permitir tudo para o dono do gasto" ON public.gastos FOR ALL TO authenticated USING (auth.uid() = user_id) WITH CHECK (auth.uid() = user_id);

-- Criação da tabela de Orçamentos/Limites
CREATE TABLE public.limites_categorias (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  user_id uuid references auth.users(id) on delete cascade not null,
  categoria text not null,
  valor_limite numeric(10,2) not null,
  CONSTRAINT unique_user_categoria UNIQUE (user_id, categoria)
);

ALTER TABLE public.limites_categorias ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Permitir tudo para o dono do limite" ON public.limites_categorias FOR ALL TO authenticated USING (auth.uid() = user_id) WITH CHECK (auth.uid() = user_id);
```
